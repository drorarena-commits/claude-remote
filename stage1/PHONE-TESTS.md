# שלב 1 — בדיקות מהטלפון

אפליקציית Claude → **Code** → "יוני קומקס".
אחרי כל בדיקה: ✅ / ❌ + מה ראית.

## 1.2 — יוני קומקס

| # | מה עושים | מה אמור לקרות |
|---|---|---|
| 1 | פותחים את "יוני קומקס" | השם בעברית תקין, נקודה ירוקה |
| 2 | `/clear` ואז: "על מה דיברנו בפעם הקודמת?" | לא יודע — שיחה נקייה. מכיר את הכללים |
| 3 | "יניב – מלאים: כמה יש מ-<מק"ט אמיתי>?" | עובר ל-comax-stock, עונה מהקבצים |
| 4 | ⭐ `/mcp` | רשימה: ג'ימייל / וורדפרס / קנבה — מחוברים? |
| 5 | ⭐ "תחפש בג'ימייל את המייל האחרון מ-<מישהו>" · "תביא את פרטי האתר בוורדפרס" · "תחפש בקנבה עיצוב בשם <משהו>" | תשובות אמיתיות, קריאה בלבד |
| 6 | ⭐ "תפתח בכרום את arenaisrael.co.il ותגיד מה הכותרת" | עובד — או ❌ (צפוי: `claudeInChromeDefaultEnabled` כבוי) |
| 7 | "תיצור קובץ בדיקה ב-C:\claude-remote\test-persona" | פוש **"צריך אישור"** מגיע לטלפון |
| 8 | "תמתין 30 שניות ותודיע לי כשסיימת" | פוש **"סיימתי"** |
| 9 | פותחים סשן **חדש** כשהראשון פתוח | נדחה (`--capacity 1`) |
| 10 | א. `/clear` בסשן הקיים · ב. לארכב אותו ולפתוח חדש | מה עובד טוב יותר → דיווח לדרור |

**אם 4–6 נכשלות — עוצרים.** Claude מציג חלופות לפני שממשיכים.

## 1.3 — ניסוי שמות (שרת בדיקה נפרד)

**א.** "בדיקה – שמות" → `echo $env:ARENA_PERSONA` → אמור לחזור `test-yaniv`.
**ב.** (רק אם א' הצליח, אחרי שה-hook הופעל) סשן חדש → "מה הפרסונה שלך?" → `test-yaniv`.
ואז `/clear` → שוב "מה הפרסונה שלך?" → עדיין `test-yaniv`.

## 1.4 — Trusted Devices (דרור)

claude.ai → הגדרות → Account → **Require trusted devices** → רישום הטלפון (Face ID).
Claude מפעיל מחדש את שרת יוני → בודקים שנפתח מהטלפון.
