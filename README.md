# claude-remote — שרתי Remote Control לסוכנים

התיקייה הזאת מנהלת את החיבור מהטלפון (אפליקציית Claude → Code) לסוכני Claude Code
שרצים על המחשב `DESKTOP-M2EJSOI`, דרך `claude remote-control` (מצב שרת).

היא נפרדת מהריפו של קומקס כי היא מנהלת גם את `the-five-agent`. **הנעילה של קומקס
(`runs/.lock`) נשארת בריפו של קומקס** — כאן אין שום נעילה.

## מה יש כאן

| נתיב | מה זה |
|---|---|
| `backup/comax-agent.cmd.orig` | העותק המקורי של קובץ ההפעלה מתיקיית Startup, לפני השינוי |
| `lock-after-boot.ps1` | נועל את המסך אחרי כניסה אוטומטית — רק אם המחשב עלה לפני פחות מ-5 דקות |
| `test-persona/` | ניסוי: האם סשן מהטלפון יורש משתני סביבה מהשרת (שלב 1.3) |
| `logs/` | לוגים — **לא נכנס ל-git**, קובץ הדיבאג עלול להכיל תוכן שיחות |

## החלטות (דרור, 29/09/2026)

- כניסות בטלפון בשלב הראשון: "יוני קומקס" בלבד (שרת קיים, שם חדש). נחמה ורונית —
  רק אחרי שניסוי 1.3 מצליח; עד אז דרך יוני בהודעה הראשונה. "גלית שיווק" — the-five-agent.
- שרת קומקס: `--spawn=same-dir` **בלבד** (אף פעם `worktree` — הנעילה ו-`data/` לא קיימים
  בעותק), `--capacity 1` ליוני ולנחמה עד שתיבנה נעילה לפי סשן.
- שיחה נקייה: `/clear` מהטלפון בתחילת כל שיחה.
- שרת קומקס רק במחשב הזה — לעולם לא בנייד.
- BitLocker לפני כניסה אוטומטית; בלי BitLocker — אין כניסה אוטומטית.
